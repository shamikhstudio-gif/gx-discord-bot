# 🤖 GX eSports Discord Bot (JavaScript - v1.0)

بوت احترافي متكامل لسيرفر **GX eSports** مبني بالكامل على ملف الإعدادات **[`src/commands.json`](file:///c:/Users/frsPC-001/Documents/eShamikh/Projects/GX%20eSports/Discord/Server%20Bots/src/commands.json)** الذي يحتوي على تفاصيل الأوامر وتصنيفها (`Public_Command: true/false`)، مع نظام تذاكر دعم فني ذكي (Threads)، وأوامر المشرفين والإشراف، وأمر **`/clear`** مع خيارات تصفية متقدمة، ونظام سجلات إدارية لحظي، ولوحة تحكم حية تتحدث كل 10 ثوان (`#system-status`)، وعزل تام لرتبة **`MEMBER`** عن أصحاب رتبة **`MANAGERS`**، وحصانة صوتية، ونظام استدعاء صوتي وبث موسيقى هادئة 24/7 مع حماية ضد السحب اليدوي (Anti-Drag).

## 🌟 هيكلية ملف الأوامر (`src/commands.json`)

جميع أوامر البوت الـ 33 مسجلة ومنظمة داخل ملف [`src/commands.json`](file:///c:/Users/frsPC-001/Documents/eShamikh/Projects/GX%20eSports/Discord/Server%20Bots/src/commands.json) بصيغة:

```json
  "name": "clear",
  "description": "مسح عدد محدد من الرسائل في القناة (مع إمكانية تحديد عضو معين)",
  "Public_Command": false,
  "category": "moderation",
  "permission": "ManageMessages",
  "options": [ ... ]
}
```

## 📜 قائمة الأوامر الـ 33 (Slash Commands)

### 🛡️ أوامر المشرفين والإدارة (`Public_Command = false`):
| الأمر | الصلاحية | الوظيفة |
|---|---|---|
| **`/clear`** / **`/مسح`** | `ManageMessages` | مسح من 1 إلى 100 رسالة مع إمكانية مسح رسائل عضو محدد فقط |
| **`/طرد`** | `KickMembers` | طرد عضو من السيرفر مع توثيق السبب |
| **`/حظر`** | `BanMembers` | حظر (Ban) عضو من السيرفر مع خيار مسح تاريخ رسائله (0-7 أيام) |
| **`/فك_حظر`** | `BanMembers` | فك الحظر (Unban) عن عضو بواسطة معرفه الرقمي (User ID) |
| **`/عزل`** | `ModerateMembers` | تطبيق تايم آوت (Timeout) على عضو لمنعه من المشاركة |
| **`/فك_عزل`** | `ModerateMembers` | إلغاء التايم آوت (Timeout) عن عضو |
| **`/تحذير`** | `ModerateMembers` | توجيه تحذير رسمي لعضو وحفظه في سجل التحذيرات |
| **`/تحذيرات`** | `ModerateMembers` | استعراض سجل المخالفات والتحذيرات السابقة لعضو معين |
| **`/مسح_التحذيرات`** | `Administrator` | مسح وتصفير سجل تحذيرات عضو بالكامل |
| **`/قفل`** | `ManageChannels` | قفل القناة الحالية ومنع الكتابة |
| **`/فتح`** | `ManageChannels` | فتح القناة الحالية وإتاحة الكتابة |
| **`/قفل_الكل`** | `Administrator` | قفل جميع القنوات النصية في السيرفر للطوارئ (Lockdown) |
| **`/فتح_الكل`** | `Administrator` | فتح جميع القنوات النصية في السيرفر |
| **`/تباطؤ`** | `ManageChannels` | ضبط وضع التباطؤ (Slowmode) في القناة بالثواني |
| **`/تغيير_لقب`** | `ManageNicknames` | تعديل أو إعادة ضبط لقب أي عضو في السيرفر |
| **`/اعطاء_رتبة`** | `ManageRoles` | منح رتبة معينة لأي عضو |
| **`/سحب_رتبة`** | `ManageRoles` | سحب رتبة معينة من أي عضو |
| **`/اعلان`** | `ManageMessages` | إرسال إعلان رسمي ملوّن باسم إدارة GX eSports في قناة محددة |
| **`/كتم_الكل`** | `MuteMembers` | كتم جميع المتواجدين في فويس البوت (مع حماية واستثناء رتبة MANAGERS) |
| **`/فك_كتم_الكل`** | `MuteMembers` | إلغاء كتم جميع المتواجدين في فويس البوت |
| **`/لوحة_التذاكر`** | `Administrator` | إرسال لوحة فتح تذاكر الدعم الفني التفاعلية بأزرار في أي قناة |
| **`/تحديث`** | `Administrator` | إعادة تحميل البرمجة ومزامنة أوامر `commands.json` والرتب فورياً |

### 🌐 الأوامر العامة للأعضاء (`Public_Command = true`):
| الأمر | الوظيفة |
|---|---|
| **`/تذكرة`** | فتح تذكرة دعم فني جديدة للتواصل مع فريق الإدارة |
| **`/استدعاء`** | استدعاء البوت لرومك الصوتي (مع نظام الاستئذان والموافقة/الرفض) |

| **`/صوت`** | تعديل وخفض أو رفع مستوى صوت الموسيقى في الفويس (من 1% إلى 100%) |
| **`/فويس_حالة`** | عرض معلومات التواجد الصوتي والمتحكم الحالي وحالة حماية السحب |

| **`/حالة`** | تقرير فحص البوت والصلاحيات ونظام المزامنة والسجلات |
| **`/بينج`** | فحص سرعة استجابة البوت وخوادم الديسكورد |
| **`/مساعدة`** | عرض قائمة المساعدة بجميع الأوامر العامة والإدارية من `commands.json` |
